Dashboard User Guide

How the system works

The bag uses an ADXL345 movement sensor and a light sensor (LDR) connected to an ESP32. If an enabled and selected sensor detects a large enough change, the bag status changes to Tampering Detected. The alarm can also sound if it is switched on.

1. Connect to the dashboard

Turn on the ESP32 and connect your device to the same Wi-Fi network. Open the ESP32's IP address in your web browser. The bottom of the dashboard should show ESP connected.

2. Choose the sensors

Use the Movement Sensor and Light Sensor ON/OFF buttons to enable or disable each sensor. Move a sensitivity slider higher to detect smaller changes. Start around 50% and adjust it after testing the bag.

3. Set up the alarm

Turn the alarm ON to allow the buzzer to sound. Use the trigger checkboxes to decide whether movement, light, or either one can set off the system. The volume slider controls the buzzer signal; the actual change in loudness depends on which buzzer is connected.

4. Check the bag status

Bag Secure means the currently selected sensors have not detected tampering. Tampering Detected means a selected sensor has passed its threshold. The light and movement readings help you test the sensors and choose a suitable sensitivity.

Troubleshooting

If the dashboard shows ESP disconnected, check the ESP32 power and Wi-Fi connection, then refresh the page. If the buzzer does not sound, check that Alarm is ON, volume is above 0%, and at least one enabled sensor is selected as a trigger. If the light sensor seems reversed, the LDR wiring or light threshold may need adjusting.
